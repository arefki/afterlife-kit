⚰️ Afterlife Kit

Template local-first untuk mengolah data CSV tanpa server: impor → validasi → olah → ekspor. Semua diproses di browser. Dibangun dengan Kiro untuk Kiroween 2026, kategori Skeleton Crew.

Dua aplikasi contoh

  • Deadline Necromancer — impor daftar tugas ber-deadline dari CSV, ekspor ke kalender (.ics).
  • Receipt Revenant — impor struk belanja dari CSV, kategorikan otomatis, lihat ringkasan per kategori dan per bulan, ekspor CSV bersih.
  • Template Demo — coba template dasarnya langsung dengan file CSV berkolom nama,nilai.

Kode sumber (MIT): github.com/arefki/afterlife-kit
