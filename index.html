⚰️ Afterlife Kit

Template gratis untuk mengolah data CSV langsung di browser — tanpa server, tanpa daftar, tanpa upload ke mana-mana. File kamu tidak pernah meninggalkan perangkatmu.

Cara kerja

  1. 1. Impor file CSV
  2. 2. Validasi otomatis
  3. 3. Olah datanya
  4. 4. Ekspor hasilnya

Coba aplikasinya

🪦 Deadline Necromancer

Punya daftar tugas ber-deadline di CSV? Impor, lalu ekspor semuanya ke kalender (.ics) sekali klik.

🧾 Receipt Revenant

Struk belanja berantakan? Impor CSV strukmu, kategorikan otomatis, dan lihat ringkasan pengeluaran per kategori dan per bulan.
